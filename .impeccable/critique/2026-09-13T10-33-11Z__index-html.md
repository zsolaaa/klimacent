## Priority Issues

**[P1] Stock/AI-placeholder imagery undermines the trust narrative**
- Why it matters: "Rólunk" sells verifiable specifics; generic lh3.googleusercontent.com stock photos one scroll away contradict that, and are an unversioned external dependency.
- Fix: Replace with real KlímaCent photos (real photography already exists: logo/auto.webp); host locally.
- Suggested command: /impeccable polish

**[P1] No visible keyboard focus state on the service-type radio pills**
- Why it matters: .service-radio-label inputs are sr-only with no :focus-visible/:focus-within style — WCAG 2.4.7 failure on the page's own conversion path.
- Fix: Add `.service-radio-label:has(:focus-visible){outline:2px solid #00316b;outline-offset:2px;}` with a :focus-within fallback.
- Suggested command: /impeccable audit

**[P2] Phone number field has no format validation**
- Why it matters: tel is required but accepts any non-empty string ("asdf" passes) — malformed number silently defeats the form's purpose.
- Fix: Add a pattern check (e.g. pattern="[0-9+ ()-]{7,}") with the same inline-error treatment as empty fields.
- Suggested command: /impeccable harden

**[P2] Redundant nav links + mobile-menu overlay bleed-through**
- Why it matters: three nav links point to the same anchor; mobile hamburger floats over the hero instead of pushing it down, so its phone CTA sits directly above the hero's near-identical CTA — reads as a glitch.
- Fix: Collapse the three links to one; give the mobile menu a solid full-height backdrop or push-down behavior.
- Suggested command: /impeccable layout

**[P3] Email address wraps awkwardly on mobile contact panel**
- Why it matters: break-all orphans a lone letter on its own line at 375px.
- Fix: Use overflow-wrap: anywhere or break-words at the @/. boundary instead of break-all.
- Suggested command: /impeccable polish
